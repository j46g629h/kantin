## 二之二、用 clasp 部署（建議做法）

設定完成後，改程式碼不必再開網頁複製貼上。

```bash
clasp.cmd push -f
clasp.cmd redeploy AKfycbyYVxnV5AZtnGkLKf0mqRTqsUmFTXI5NoaREPQYPveaCrAt1oW8JShMaZjEos6J5NVr-Q -d "改了什麼"
```

`redeploy` 沿用同一組部署 ID，**API 網址不會變**，前端不用改。

| 注意事項 | 說明 |
|---|---|
| Windows 要用 `clasp.cmd` | 直接打 `clasp` 會被 PowerShell 執行原則擋住（`clasp.ps1` 未簽章） |
| 需先開啟 API 權限 | https://script.google.com/home/usersettings 的「Google Apps Script API」要開啟 |
| 換電腦要重新登入 | `clasp login`（macOS 不用加 `.cmd`） |
| 憑證位置 | `~/.clasprc.json`，不在專案內，已列入 `.gitignore` |
| `push` 會刪除線上多餘檔案 | 線上檔案會被同步成跟 `gas/` 一模一樣 |

## 三、⚠️ 重新部署的正確步驟（手動方式，備用）

改完程式碼後：

1. 右上角 **部署** → **管理部署作業**
2. 找到現有的部署，點右上角**鉛筆圖示（編輯）**
3. 「版本」下拉選 **新增版本**
4. 按 **部署**

**網址不會變，前端不用改。**

### ❌ 絕對不要按「新增部署作業」

那會產生一組**全新的網址**，舊網址雖然還能用但停在舊版本，
你會遇到「程式明明改了卻沒生效」，然後找一個下午。

## 四之二、管理者帳號初始設定（第 3 階段，只做一次）

前兩個步驟都在 **Apps Script 編輯器**裡執行，不是在網頁上。

開啟方式：Google Sheet →上方選單「擴充功能」→「Apps Script」。

### 步驟 1：建立兩個新分頁

1. 編輯器上方有一排小按鈕，中間有一個**函式下拉選單**
2. 選 `setupAdminSheets`
3. 按左邊的 **▷ 執行**
4. 下方「執行紀錄」出現「完成」即成功

會建立 `管理者名單` 與 `回覆範本` 兩個分頁。重複執行是安全的（已存在就略過）。

### 步驟 2：建立你自己的超級管理者帳號

1. 函式下拉選單選 `createSuperAdmin`
2. 按 **▷ 執行**
3. **執行紀錄會印出一組隨機的初始密碼——先複製起來**

```
✔ 已建立管理者帳號
  帳號：j46g629h@gmail.com
  角色：SUPER
  初始密碼：Kd7mQx4pRt9n     ← 複製這一行
```

> ⚠️ 密碼**只會出現這一次**。Sheet 裡只存加密後的雜湊值，查不回來。
> 沒記下來也沒關係：執行 `resetAdminPassword()` 會產生一組新的。

**為什麼密碼是程式隨機產生、不是自己設定的？**
因為 `gas/Setup.js` 會跟著 git 上傳到 GitHub。密碼打在程式碼裡就等於公開貼在網路上。

### 步驟 3：登入並改成自己的密碼

1. 開 https://j46g629h.github.io/kantin/admin.html
   （或從首頁最下方的「管理者登入」小字進入）
2. 帳號 `j46g629h@gmail.com` + 剛剛複製的初始密碼
3. 系統會**強制**你設定新密碼：至少 8 個字，要有英文字母和數字
4. 設定完成後就會進入案件列表頁

## 四之三、管理者帳號的維運

**第 3-5 關做完之後，日常操作都在網頁上：**
用超級管理者登入 → 案件列表右上角的〔帳號管理〕→ 新增 / 停用 / 啟用 / 重設密碼。
（這個連結只有超級管理者看得到。）

| 情況 | 怎麼處理 |
|---|---|
| 新增管理者 | 帳號管理頁〔新增管理者〕。**初始密碼只顯示一次**，關掉就查不回來（Sheet 裡只存雜湊），忘了就再重設一次 |
| 某人忘記密碼 | 帳號管理頁那一列的〔重設密碼〕。預設是**自己輸入一組**，也可以改選**系統產生隨機密碼**。兩種都會解除登入鎖定、讓他目前的登入立刻失效，並要求他第一次登入就改掉 |
| 有人離職 | 帳號管理頁那一列的〔停用〕。他手上的登入會**立刻**失效，不用等 6 小時 |
| 離職的人回鍋 | 同一列按〔啟用〕，密碼不變 |
| **自己**忘記密碼 / 被鎖住 | 網頁上救不了（不能重設自己）。到 Apps Script 編輯器執行 `resetAdminPassword()`，先把裡面的 `ACCOUNT` 改成你的帳號 |
| 想改某人的名字 | 帳號管理頁那一列的〔改名字〕。對方**不會**被登出，他頁面上的「你好，OOO」下次重新整理就會變。已處理過的案件仍顯示當時的名字（那是稽核紀錄，刻意保留）|
| 想改某人的角色 | 網頁上刻意沒有這個按鈕。要交接超級管理者的話，建一個新的 SUPER、再停用舊的即可 |
| 想看某人現在的密碼是什麼 | **看不到，任何人都看不到**，見下方說明 |

> **自己輸入密碼時，系統會擋掉跟其他管理者重複的那一組**，
> 出現「已經有其他管理者在用這組密碼了」就換一組。
> 它不會告訴你是誰在用——說了的話，這個功能就變成可以拿來猜別人密碼的工具。
>
> 想不到要設什麼就改選「系統產生」，它是 12 個字、猜不到的。

**幾件網頁上會被擋下來的事（這是刻意的）：**

- 不能停用自己 —— 手滑就把自己關在門外
- 不能停用**最後一位啟用中的超級管理者** —— 停掉就沒人進得去帳號管理頁
- 不能重設自己的密碼 —— 要改自己的密碼請用「變更密碼」

### 為什麼看不到別人的密碼

Sheet 存的是加鹽 + SHA-256 迭代 1000 次的結果，**這個運算單向不可逆**——
不是系統不給你看，是連系統自己都算不回去。這是所有正經系統的作法。

想確認「我剛剛的重設有沒有生效」，看那一列的**「密碼最後變更」時間**
（需先執行一次 `migrateAddPasswordChangedAt()`，見下方）。

忘記幫某人設了什麼密碼？重設一次就好，三個點擊的事。

**「待本人自行設定密碼」這個標籤不是錯誤。**
它的意思是「這組密碼是你幫他設的，他還沒換成只有自己知道的」。
你剛幫他重設完，這個標籤本來就該在——
等他自己登入改過密碼之後就會消失。

**絕對不要手動編輯這兩欄**：`密碼雜湊`、`密碼鹽值`。
改壞了該帳號就永遠登不進去，只能重設密碼。

**停用請用網頁，不要直接改 Sheet。**
直接在 `管理者名單` 分頁把「狀態」改成 `DISABLED` 也會生效，
但**不會**作廢對方手上的 token——他在接下來 6 小時內照樣能改案件。
（離職不論用哪種方式都**不要刪除該列**，否則歷史案件的處理者會對不上。）

### 報表要寄給誰

**收件人 = 啟用中的超級管理者 ＋「選項設定」分頁裡的額外名單。**
一般管理者**不會**收到（這是刻意的，見規格 §10）。

**要多寄給一個人**（廠長、秘書…）：到「選項設定」分頁加一列——

| 類型 | 代碼 | 中文顯示 | 印尼文顯示 | 排序 | 啟用 |
|---|---|---|---|---|---|
| `REPORT_TO` | 對方的 **Email 地址** | 用途說明（例如「廠長」）| 可留空 | 1 | ✔ |

⚠️ 這個類型的**「代碼」欄放的是 Email**，跟其他類型不一樣
（其他類型放的是 `LOC_02` 這種識別碼，這裡的識別碼本來就是信箱）。

**不想寄給某人了**：把那一列的「啟用」改成 FALSE，**不要刪掉那一列**——
留著才知道以前寄給誰，日後要恢復也只要改回來。

**兩個帳號填同一個信箱不會收到兩封**，系統會自動去重。

想確認實際會寄給誰：執行 `checkMailSetup()`，它會把收件人清單印出來。

### 一次性升級腳本

| 函式（在 `Setup.gs`）| 用途 | 狀態 |
|---|---|---|
| `migrateAddPasswordChangedAt()` | 在「管理者名單」加上「密碼最後變更時間」欄位 | ✅ 已執行（2026-08-21，第 11 欄）|

**不跑也不會壞。** 這個欄位在程式裡標成「選填」，Sheet 上還沒有的時候
帳號管理頁只是不顯示那個時間，其他功能完全正常。
（這是線上事故 1 的正確作法——那次加了欄位就直接部署，導致完全無法登入。）

跑完之後，既有帳號那一欄會是空的：系統不知道他們的密碼是什麼時候設的，
只能從下一次變更開始記錄。這是正常的。

| 日期 | 問題 | 解法 |

| 2026-08-22 | 加了寄信功能後第一次執行，授權畫面明明按過了，卻回「已寄出 0 封（失敗 2 封）」 | `MailApp.sendEmail` 需要 `script.send_mail` 權限，但 Apps Script 是**掃描程式碼推算**要哪些權限的，剛推上新程式碼時它可能還在用舊的權限清單。**解法：再執行一次**，第二次的授權畫面就會包含新權限。程式已改成把這種錯誤跟一般寄信失敗分開講，執行紀錄會直接告訴你「再執行一次就好」 |
| 2026-08-21 | 串接檢查 `cat gas/Config.js gas/Utils.js gas/Main.js gas/*.js` 必定報 `SyntaxError: Identifier 'SHEET_ID' has already been declared`，看起來像程式壞了 | `gas/*.js` 已經包含前面列的那三個檔案，等於串了兩次。正確寫法是 `cat gas/*.js > /tmp/all.js && node --check /tmp/all.js`。已修正 `CLAUDE.md` |
| 2026-08-21 | 帳號停用後，對方在 6 小時內還是能改案件 | `withAuth()` 只讀 token 裡的 session 快照，不會回頭查 Sheet。已加 `revokeSessionsForAccount()`，停用 / 改角色 / 重設密碼時一併作廢對方所有 token |
