## 三、⚠️ 重新部署的正確步驟

改完程式碼後：

1. 右上角 **部署** → **管理部署作業**
2. 找到現有的部署，點右上角**鉛筆圖示（編輯）**
3. 「版本」下拉選 **新增版本**
4. 按 **部署**

**網址不會變，前端不用改。**

### ❌ 絕對不要按「新增部署作業」

那會產生一組**全新的網址**，舊網址雖然還能用但停在舊版本，
你會遇到「程式明明改了卻沒生效」，然後找一個下午。

## 四、時區設定

Apps Script 編輯器左側 **專案設定（齒輪）** → 時區 → **(GMT+07:00) Jakarta**

沒設的話案件編號和月報的日期會全部錯開。

## 五、踩坑紀錄

> 遇到問題和解法都記在這裡，下次就不用重新查。

| 日期 | 問題 | 解法 |
|---|---|---|
| 2026-08-18 | GitHub Pages 的資料夾下拉只有 `/(root)` 和 `/docs`，選不到 `/web` | GitHub 的限制，只支援這兩個位置。已把前端檔案（`index.html`、`css/`、`js/`）移到專案根目錄，Pages 設定選 `/(root)`。**前端檔案以後都放根目錄，不要再移到子資料夾。** |
| 2026-08-18 | 用 `curl` 測 POST 出現 `Error 411 Length Required` | curl 跟隨 Apps Script 的轉址時會弄丟標頭，不是程式問題。改用瀏覽器或 Node 的 `fetch` 測試即正常。 |
