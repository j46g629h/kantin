依你的三點回饋重做。下面每一項都用真實尺寸呈現。

① 你發現的「粗糙」其實是一個 bug

上一版我用的是 SVG 的 <text> 搭配 font-family。 SVG 的文字是用「觀看者自己電腦上的字型」畫的—— 所以同一個圖示在 Windows 是 Segoe UI、在 iPhone 是 Helvetica、在 Android 又是別的。 圖示會在不同手機長得不一樣。

新版把每個字母改成幾何路徑（直線與橢圓弧），完全不依賴字型， 所有裝置上都一模一樣。而且線寬、字距、高度全部量過對齊。
舊：系統字型
新：幾何路徑

C 的字形橢圓弧，不是正圓——真字型裡 C 本來就比圓形窄

② 「PCI GA」可以放進去——但要分成兩個檔案

分頁圖示只有 16×16。「PCI」三個字每個約 3.8px 已是極限， 再加「GA」會變成一團灰糊。

但這兩個尺寸本來就可以用不同的圖。 瀏覽器與手機會依尺寸各自挑檔案——這是標準做法，不是取巧。

③ 名稱：我建議跟你想的相反

你提議「app 名稱＝PCI GA、圖示內文字＝Kantin PCI」。我建議反過來。

圖示只有 2–3 個字的空間，所以要放最短、最獨特的識別＝PCI（大尺寸再加 GA）。 Kantin PCI 是 10 個字，放進 16px 的方塊裡一定糊。

而圖示下面那行字是作業系統畫的，永遠清楚。 它應該回答「這是什麼」——員工的主畫面上有幾十個 app， 看到 PCI GA 他不會知道那是餐廳回報；看到 Kantin PCI 就知道。

這跟頁首「機構標記 + 產品名」是同一個邏輯：圖示放機構、名稱放產品。
