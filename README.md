# PCI 餐廳回饋系統

PCI adidas 工廠員工餐廳問題回報系統。

- 員工掃 QR Code 用手機回報餐廳問題
- 管理者透過網頁介面追蹤與回覆
- 資料存於 Google Sheet，零成本運行

## 目錄結構

| 路徑 | 說明 |
|---|---|
| `docs/` | 規格書、部署筆記 |
| `web/` | 前端（發布到 GitHub Pages） |
| `gas/` | Google Apps Script 程式碼備份 |
